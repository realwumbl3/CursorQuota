# CursorQuota

A small Chrome extension for keeping Cursor's included monthly usage on track.

On the Cursor **Spending** page, it adds a quota chart for Cursor Models and Other Models. Each chart shows:

- current usage
- daily budget for the remaining days
- ideal pace to reach the reset date
- projected usage at reset

Every visit to the Spending page records the displayed percentage. Each chart spans the current billing period—from its start through the reset date—and projects forward from the latest point.

## Install

1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Choose **Load unpacked** and select this folder.
4. Open [Cursor Spending](https://cursor.com/dashboard/spending).
